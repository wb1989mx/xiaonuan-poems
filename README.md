# 儿童学习平台

面向 8 岁孩子的诗词阅读互动平台。iPad 横屏、一诗一屏、PWA 发布。

## 目录

| 目录 | 内容 |
|---|---|
| `方案/` | 设计与技术方案，v0.2 为现行版 |
| `素材库/` | 全部美术与音频素材，含规范文档与台账 |
| `工具/` | 抠图、归一、压图、动效预览脚本 |
| `app/` | 前端工程（Vite + React + TS），`app/src/content/poems/` 为诗词 JSON |

## 六条不能忘的结论

1. **整鹿单层**，不切颈线，也不切围巾尾端。分部件生成、横切对齐、切尾补窟窿三条路都已实测或推演过，不成立。
2. **每张图单独取背景色**。生图给的"品红"每张都不同，硬编码必翻车。
3. **新姿态必须重跑头宽归一**。提示词管不住头身比。
4. **闭眼是程序画的，不是生成的**。生成式改眼会有局部漂移和矩形接缝，见 `素材库/00_规范/素材清单与制作规范.md` §4.6。
5. **配音整首连录、程序切句**。四句气息要连贯；十首十条。停顿够长（2/2/2/4 秒）时按静默确定性切；停顿短又带导语时，只能靠语音识别的时间戳对齐来切。
6. **ffmpeg 用 `-ss`/`-t` 必须写在 `-i` 前面**。写在后面时滤镜拿到的是原始时间戳，`afade=t=out` 会把整段淡成静音，且大小、时长都正常，只有电平全是 −91dB。

## 环境

- 本项目在新机器 `DESKTOP-0K70D4C` 上，路径 `D:\Doubao\活学活用\儿童学习平台`
- ffmpeg 9.0.2 在 `C:\Users\win\tools\ffmpeg`
- Python 必须用全路径 `C:\Users\win\AppData\Local\Programs\Python\Python312\python.exe`（`py -3.12` 已不可用）
- 构建流程：`cd app && npm run build`，再跑 `工具/make_precache.py` 生成 `dist/precache-manifest.json`
- 离线验收：`工具/test_offline.py`（连无头 Chrome 的 CDP，切离线后回读页面）

## 发布

- 代码仓库：<https://github.com/wb1989mx/xiaonuan-poems>（公开）
- 线上站点：<https://wb1989mx.github.io/xiaonuan-poems/>（GitHub Pages，源为 `main` 分支 `/docs` 目录）
- `docs/` 是 `app/dist` 的完整拷贝，每次改完页面按顺序来：`npm run build` → `工具/make_precache.py` → 用 `app\dist` 覆盖 `docs\` → 提交推送。少任何一步，线上都是旧站或清单为空。
- 字体改了文案要重跑 `工具/build_fonts.py`，否则新字回落到系统字体。
