## 二、这批录音的实际结构（与文案要求的偏差）

| 偏差 | 实测 | 处理 |
|---|---|---|
| 带了导语 | 十条都先报「题名 + 作者 + 一句解说」，占 7.6–11.4 秒，最长一条导语 11.4 秒 | 整段切掉，只保留诗；导语文字仍按方案走页面文字 |
| 句间停顿偏短 | 0.3–0.5 秒，不是文案要求的 2 秒；句四之后也没有 4 秒 | 改按词级时间戳找句界，切点落在真实空隙里 |
| 诗的分段不统一 | 02/05/08/09/10 整首一口气念完；01/03/04/06/07 是前两句、后两句各停一下 | 整读保留原始中段停顿；逐句仍按四句边界切 |

所以「十条整段 → 50 个文件」这件事本身成立，只是不能靠静默阈值。

## 三、切分方法

原 `工具/split_voice.py`（按 ≥1.2 秒静默切）在这批录音上直接失效：用 −32dB 阈值扫十条，最长静默只有 0.96 秒，找不到四个切点。换成识别对齐：

1. `工具/asr_probe.py` 用 faster-whisper `small`（int8、CPU）出词级时间戳。解码不用它自带 `av` 通道（版本不兼容），先用 ffmpeg 转 16k 单声道再喂 numpy 数组。
2. `工具/cut_from_asr.py` 读识别结果，先掐导语：取前半段（<55% 时长）里最长的一处停顿，其后才是诗。这一步很关键——咏鹅第一句是「鹅鹅鹅」，不掐导语时对齐会把导语里的「鹅」当成诗句首字，句一凭空长到 12 秒。
3. 再把四句诗文与识别字串做加权对齐（同字 1.0、同音 0.72、同声母 0.35、空 −0.55），得到每句的起止时间。
4. 相邻两句之间取空隙中点当切点；每段首尾留白、40ms 淡入 60ms 淡出、`loudnorm` 归一到 −16 LUFS，输出 48k/24bit 单声道 WAV。
5. 整读 = 首句起 → 末句止，中间的换气停顿原样保留；同时出 `0X-audio.json`（每段起止、时长、文件名）与 `_预览/录音切点_0X.png`（四条切点标在波形上）。

## 四、校验

`工具/qc_voice.py` 把切好的 50 个文件再识别一遍，逐字比对预期诗句：50 个文件全部只含本句（没有导语、没有邻句），四句顺序在整读里也完整。识别率低于 80% 的都是同音错字（如「曲项」听成「吃相」、「草长」听成「曹掌」），属识别误差，不是内容错误。

## 五、已知瑕疵与待人工核

- **多音字读音机器判不了**：曲（qū）、觉（jué）、藏（cáng）、露（lù）、长（zhǎng）、更（gèng）六处，识别只给同音字，无法区分声调与读法。需要你对着文案听一遍，读错的只重录那一句即可（单句重录可以直接替换 `XX-2.wav` 这类单文件）。
- **《小池》「树阴 / 树荫」**：以孩子课本用字为准，音频不受影响，影响的是页面文字。
- **句间停顿偏短**在听感上会有影响：逐句点读时上一句尾巴接下一句起点很紧，页面上的句间过渡动画要留一点时间，不要把两句连播当成无间隙。

## 六、复跑命令

```
py -3.12 工具/asr_probe.py 素材库/诗词/_录音原档 --json 素材库/诗词/_录音原档/_asr
```

## 七、踩坑记录

| 坑 | 现象 | 原因与解法 |
|---|---|---|
| `-ss` 放在 `-i` 之后，滤镜整段静音 | 切出的文件 −91dB，识别全空、满屏「字幕索兰娅」 | 输出侧 seek 时滤镜看到的是原始时间戳，`afade=t=out:st=2.68` 落在时间轴起点之前，等于整段已被淡没。改成输入侧 seek（`-ss` / `-t` 写在 `-i` 前面），时间戳归零后正常 |
| faster-whisper 直接吃 m4a | `open() got an unexpected keyword argument 'metadata_errors'` | 装到的 `av` 版本与 1.2.1 不兼容；绕开它自带的解码，自己用 ffmpeg 转 16k 单声道 WAV 再读 numpy |
| 3 秒短片段识别出胡话 | 「字幕索兰娅」「这次的节奏请不吝点赞订阅」 | 音频接近静音时的幻觉串，属识别噪声，看到就丢 |
| 静默阈值切分整批失效 | 十条都找不出 4 个切点 | 手机录音句间只停 0.3–0.5 秒；按「≥1.2 秒」的预设天然找不到。这类录音只能用识别时间戳切，不能调阈值硬凑 |
| 同音字导致句界跑偏 | 咏鹅句一被算成 12 秒 | 导语里也有「鹅」，对齐会去抓更早的那个。先掐导语再对齐 |

## 八、下一批录音建议（以后加诗或重录时用）

前面这批是「整段带导语、句间几乎不停」，切得出来但费了两轮返工。下一批按这个录，能省掉识别对齐这一步：

1. 不报题目、不报作者、不说解说——直接念诗。
2. 句间停 2 秒、句四之后停 4 秒、整读念完停 2 秒再停录。
3. 停顿里不出声、不挪手机。

只要停顿守规矩，`工具/split_voice.py` 那条老链路就是确定性的，不需要识别。
